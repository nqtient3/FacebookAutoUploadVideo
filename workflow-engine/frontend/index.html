Trợ Lý Lấy Page ID & Page Access Token

Quét tự động Fanpage bạn quản lý • Trích xuất Token vĩnh viễn 1-Click
💡 Cách hoạt động: Dán mã Token (User Token từ Graph API Explorer hoặc Page Token). Hệ thống sẽ tự động quét toàn bộ Fanpage bạn quản lý và trích xuất đồng thời Page ID và Page Access Token vĩnh viễn cho bạn.
🪄
Dán mã Token vào ô phía trên rồi nhấn "Quét Fanpage"
Chưa có mã token? Chuyển sang tab "Hướng Dẫn 3 Bước" để tạo miễn phí trong 1 phút!
🎯 Tra cứu Page ID: Nhập đường dẫn link Fanpage bất kỳ (VD: https://facebook.com/ThoBayMau hoặc link chứa profile.php?id=...) để tìm dãy số Page ID chuẩn.
1️⃣ Bước 1: Mở Meta Graph API Explorer
🚀 Mở Graph Explorer ↗
Truy cập công cụ chính thức của Meta Facebook. Đăng nhập tài khoản Facebook đang quản trị Fanpage của bạn.
2️⃣ Bước 2: Chọn quyền truy cập (Permissions)
Tại cột bên phải, bấm vào Add a Permission và chọn 4 quyền thiết yếu sau:
pages_show_list pages_read_engagement pages_manage_posts publish_video
3️⃣ Bước 3: Bấm Generate Access Token & Dán vào Trợ Lý
Bấm nút Generate Access Token màu xanh trên màn hình Facebook -> Xác nhận cấp quyền -> Copy toàn bộ chuỗi ký tự Token bắt đầu bằng EAAG... -> Quay lại Tab Quét Tự Động và dán vào là xong!
✨ Đặc quyền: Page Access Token được tạo thông qua tài khoản quản trị viên sẽ có tính chất không bao giờ hết hạn (Never Expire), giúp quy trình auto upload hoạt động liên tục 365 ngày mà không cần lấy lại token!
